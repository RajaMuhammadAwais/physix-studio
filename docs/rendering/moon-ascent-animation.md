# Moon Ascent Animation

The scene uses a stable documentary split-screen composition. The left side contains a procedural space background, Earth, physical Moon, and bounded motion trail space. The right side contains axes, labels, a progressively revealed Height vs Time curve, and a smaller procedural Moon cursor. The bottom dashboard displays time, height, velocity, and acceleration. The top equation panel displays the analytical position and velocity equations and highlights `v = 0` after the physics event detector reports maximum height.

The current test environment does not have Manim installed, so a real video render has not been claimed or verified here. The renderer availability check and all renderer-neutral state mappings are tested. Installing the optional dependency and running the CLI is the next verification step.
